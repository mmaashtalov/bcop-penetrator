# Использование BCOP Dialogue Core

## Основной сценарий

1. В боковой панели выберите цель текущего разговора.
2. Вставьте новое сообщение банка или коллектора.
3. Проверьте обезличенную копию: BCOP автоматически скрывает часть идентификаторов, но не может гарантировать удаление всех персональных данных.
4. Нажмите «Проверил, передать в анализ» только если в копии нет лишних сведений. При отмене исходный текст остаётся в поле ввода и никуда не отправляется.
5. Проверьте обнаруженные тактики, сигналы давления и рекомендуемый следующий шаг.
6. Скопируйте вариант ответа или нажмите «Использовать» — выбранный текст попадёт в историю текущей вкладки.
7. Вставьте следующую реакцию собеседника: контекст продолжится автоматически.

## Запуск без ключа

В `.env` оставьте `DEMO_MODE=true`. Сервер вернёт детерминированный демо-анализ и пометит его как «ДЕМО».

## Реальный AI-контур

Ключ должен находиться только на сервере:

```dotenv
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4o-mini
DEMO_MODE=false
```

Нельзя использовать `VITE_OPENAI_KEY`: любые переменные `VITE_*` попадают в клиентскую сборку.

## Приватность и хранение

- По умолчанию история не записывается в `localStorage`: она существует только в памяти вкладки и исчезает после обновления страницы или закрытия вкладки.
- Включить сохранение можно отдельной галочкой «Сохранять историю на этом устройстве». При этом исходные тексты сохраняются локально в браузере этого устройства до ручного удаления.
- Кнопка «Удалить все диалоги» очищает все сохранённые сессии. Восстановить их после удаления нельзя.
- Перед каждой отправкой интерфейс показывает обезличенную копию нового сообщения. Маскируются телефон, email, карта, счёт, СНИЛС, номер документа/ИНН и часть форматов ФИО; адреса и редкие идентификаторы нужно проверять вручную.
- Сервер повторяет маскировку независимо от браузера. В логи не пишутся текст переписки, ответ модели или IP-адрес клиента.

## Защита API

`/api/dialogue/analyze` ограничен по частоте: по умолчанию 20 запросов за 60 секунд на клиента. При превышении сервер вернёт HTTP `429` и заголовок `Retry-After`.

Настройки в `.env`:

```dotenv
RATE_LIMIT_MAX_REQUESTS=20
RATE_LIMIT_WINDOW_MS=60000
TRUST_PROXY=false
```

`TRUST_PROXY=true` включайте только за доверенным reverse proxy, который удаляет подставные заголовки `X-Forwarded-For`.

## Ограничения

- Варианты ответа являются черновиками и требуют проверки человеком.
- BCOP не устанавливает юридическое нарушение по одному сообщению.
- Сервер ограничивает историю последними 30 сообщениями и общий объём контекста.
- Автоматическая маскировка снижает риск, но не заменяет ручную проверку перед передачей данных внешнему AI-провайдеру.
