# Публичное мобильное демо BCOP

## Назначение

Это отдельная статическая сборка для демонстрации интерфейса на телефоне. Она не использует сервер BCOP, OpenAI или форму ввода; посетитель может только переключать три заранее подготовленных вымышленных сценария.

Ожидаемый адрес после первого успешного развёртывания:

`https://mmaashtalov.github.io/bcop-penetrator/`

## Граница данных

- Каждый текст в сборке явно помечен как демонстрационный и вымышленный.
- В публичной версии нет поля ввода, `localStorage`, API-клиента и отправки данных.
- В HTML добавлена CSP с `connect-src 'none'`: браузер блокирует любые сетевые обращения со страницы.
- Черновики ответов показаны только для просмотра; копирование, сохранение и отправка отключены.

## Сборка и проверка

```bash
pnpm check:public-demo
```

Команда создаёт `dist-public-demo/` и проверяет:

- наличие `index.html` и `.nojekyll`;
- наличие явной маркировки публичного демо и CSP;
- отсутствие `/api/dialogue/analyze`, локального сервера и OpenAI-ключа в артефакте.

## Развёртывание

Workflow `.github/workflows/deploy-public-demo.yml` публикует только текущую ветку Draft PR `codex/bcop-dialogue-core-v0.2` через GitHub Pages. `main` не участвует и не меняется.

Перед первым запуском в настройках репозитория GitHub Pages должен быть выбран источник **GitHub Actions**. После этого каждый push в ветку демо или ручной запуск workflow обновляет ссылку.

## Приёмка на телефоне

1. Откройте ссылку в обычном браузере телефона.
2. Убедитесь, что сверху видна маркировка «Публичное read-only демо».
3. По очереди переключите «Давление сроком», «Запрос документов» и «Граница контакта».
4. Для каждого кейса проверьте: сообщение меняется, справа появляются анализ и три черновика.
5. Убедитесь, что нет поля ввода, кнопки отправки, сохранения истории или запроса разрешений.
6. В DevTools при возможности проверьте, что не выполняются вызовы `/api/*`; это дополнительно блокируется CSP.

## Ограничение

Ссылка демонстрирует продуктовый поток и границы безопасности, но не является публичной AI-бетой. Реальные или даже обезличенные переписки в этот контур не вводятся.
