# Приёмка BCOP Dialogue Core v0.2

Цель: подтвердить на телефоне, что пользователь получает безопасный, понятный следующий шаг, а не юридическое заключение. Для приёмки использовать только вымышленные или обезличенные сообщения.

## Подготовка

```bash
pnpm install
pnpm build
pnpm smoke:api
```

Для интерфейса запустите в двух процессах:

```bash
pnpm dev:api
pnpm dev
```

Откройте адрес Vite в мобильном браузере. Для этой приёмки в `.env` должен быть `DEMO_MODE=true`.

## Обязательные сценарии

| Сценарий | Действие | Ожидаемый результат |
| --- | --- | --- |
| Давление сроком | Выбрать цель «снизить давление», вставить: «Оплатите сегодня, иначе обратимся к родственникам и в суд». | Карточка помечена «ДЕМО»; риск — высокий; видны сигналы срочности и последствий; доступны три черновика ответа. |
| Запрос документов | Выбрать цель «получить информацию», вставить: «Вы обязаны оплатить долг немедленно». | Рекомендуемый следующий шаг — запросить документы; вариант `documents` требует наименование организации, основание, расчёт и подтверждение полномочий. |
| Граница контакта | Выбрать цель «прекратить контакт», вставить нейтральное повторное требование. | Рекомендуемый следующий шаг — обозначить границы; варианты не содержат угроз, оскорблений, обещания оплаты или признания долга. |
| Ошибка API | Отправить `POST /api/dialogue/analyze` с `goal: "unknown"`. | HTTP `400`, ответ содержит «Неизвестная цель диалога.»; в интерфейсе ошибка показывается пользователю без технического стека. |

## Критерии приёмки

- История выбранного диалога учитывается при следующем анализе.
- Выбранный черновик добавляется в историю как сообщение пользователя.
- При `DEMO_MODE=true` сервер не обращается к OpenAI, даже если ключ задан в окружении.
- `pnpm check` завершается успешно: тесты, ESLint, TypeScript, production build и HTTP smoke-test.

## Граница текущей версии

Переписка пока хранится в `localStorage`; до закрытия privacy-блока не используйте реальные персональные данные, реквизиты, пароли или полные неанонимизированные диалоги.
