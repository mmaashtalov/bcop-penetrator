# Трек под вакансию — public demo

Автономная демонстрационная версия сервиса оценки достижимости вакансии и генерации персонального обучающего трека.

## Публичные ссылки

- Актуальная версия: https://raw.githack.com/mmaashtalov/bcop-penetrator/main/vacancy-adaptation-demo/index.html
- Стабильная версия Sprint 8 demo: https://rawcdn.githack.com/mmaashtalov/bcop-penetrator/d95a2e91fa8e625fdede1f0bee4fc4668701db82/vacancy-adaptation-demo/index.html
- Резервный HTML Preview: https://htmlpreview.github.io/?https://github.com/mmaashtalov/bcop-penetrator/blob/main/vacancy-adaptation-demo/index.html

## Режим работы

- полностью выполняется в браузере;
- не требует API-ключей;
- резюме не отправляется на сервер;
- содержит три готовых демо-кейса и rule-based обработку пользовательского текста;
- не подменяет production backend Sprint 8 с LLM, provenance и PostgreSQL.
